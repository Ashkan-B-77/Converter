# Case Converter

This is a simple web application which converts letters in the input box to Uppercase or lowercase.

## How to use

- **Convert the text to Uppercase or lowercase**
― Type in the input box and click *TO UPPERCASE* to convert the text to uppercase and get a list item of the same text.
― Type in the input box and click *to lowercase* to convert the text to lowercase and get a list item of the same text.
